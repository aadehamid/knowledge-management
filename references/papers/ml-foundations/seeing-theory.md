# Seeing Theory

A visual introduction to probability and statistics.

[ Start ](https://seeing-theory.brown.edu/basic-probability/index.html)

 Seeing Theory was created by Daniel Kunin while an undergraduate at Brown University. The goal of this website is to make statistics more accessible through interactive visualizations (designed using Mike Bostock’s JavaScript library [D3.js](https://d3js.org/)).

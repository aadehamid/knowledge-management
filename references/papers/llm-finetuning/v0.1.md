# Hands-On Modern RL Open Textbook v0.1.5

这是《Hands-On Modern RL：现代强化学习实战》的开放教材版本发布页。本版开始同时提供中文 PDF 与英文 PDF。

## 下载

- [下载中文 PDF 电子书](https://github.com/walkinglabs/hands-on-modern-rl/releases/download/v0.1.5/hands-on-modern-rl-open-textbook-v0.1.5.pdf)
- [Download English PDF textbook](https://github.com/walkinglabs/hands-on-modern-rl/releases/download/v0.1.5/hands-on-modern-rl-open-textbook-en-v0.1.5.pdf)

## 本版内容

- 新增完整英文版 PDF：基于 `docs/en` 英文课程内容构建
- 英文站点内容补齐：中文页面均有英文对应页，清理占位符和半截翻译
- 英文图片资源不复制，统一引用中文侧已有图片资产
- 对齐中英文标题编号，修复旧章节号残留
- LaTeX 书籍版排版，不是网页打印导出
- README logo 书籍封面、本书简介与版本说明
- 可点击目录、PDF bookmarks/outlines、章节开篇页
- 页眉 GitHub 链接、页脚作者信息和右下角页码
- 作者信息：WalkingLabs；散步 [https://github.com/sanbuphy](https://github.com/sanbuphy)
- GitHub 仓库信息：[https://github.com/walkinglabs/hands-on-modern-rl](https://github.com/walkinglabs/hands-on-modern-rl)
- GIF/WebP/AVIF 构建时抽帧转 PNG，SVG/Mermaid 构建时预渲染为 PDF/PNG
- Ghostscript 优化 PDF 结构与字体，适合 Release 下载与离线阅读
- 局部参考文献、脚注和常见 Markdown 结构清理
